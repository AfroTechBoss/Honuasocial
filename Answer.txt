---

# 1. Point System Design (Gamified Rewards)

You want points to encourage **posting + meaningful engagement**, but prevent spam.

### Base Actions

| Action                 | Points |
| ---------------------- | ------ |
| Post a green action    | +1     |
| Verified eco action    | +5     |
| Like from another user | +0.1   |
| Comment                | +0.3   |
| Share                  | +0.5   |
| Post reported as fake  | −5     |

### Quality Multiplier

Instead of only counting engagement, you weight it.

Example formula:

```
Total Points = Base Post Points + Engagement Score × Credibility Score
```

Where:

**Engagement Score**

```
Engagement Score = (likes × 0.1) + (comments × 0.3) + (shares × 0.5)
```

**Credibility Score**

This ensures posts with **proof get more points**.

| Evidence          | Multiplier |
| ----------------- | ---------- |
| Text only         | 1x         |
| Photo             | 1.5x       |
| Video             | 2x         |
| Location verified | 2.5x       |

Example:

User posts video planting a tree.

```
Base = 1
Engagement = 40 likes + 10 comments + 5 shares
Score = (40×0.1)+(10×0.3)+(5×0.5)=4+3+2.5=9.5
Credibility = 2

Total = 1 + (9.5 × 2)
Total = 20 points
```

# 2. Determining if Posts Are Eco-Friendly

This is the **hardest problem**.

I would combine **AI + community moderation + proof systems**.

### 1️⃣ AI Content Detection

AI scans posts for eco activities.

Examples it recognizes:

* Tree planting
* Recycling
* Using reusable bags
* Solar installation
* Beach cleanup
* Composting
* Cycling instead of driving

AI models analyze:

* **Image recognition**
* **Text keywords**
* **Video frames**

Example detection:

```
Image: Person holding trash bag at beach
Text: “Cleaned my local beach today”
AI confidence: 0.87 → Eligible
```

If confidence is low:

→ Send for manual review.

---

### 2️⃣ Community Verification

Users can verify others.

Example:

"Confirm this action happened."

If **5 trusted users confirm → bonus points**.

If people flag:

```
If reports > threshold → post investigated
```

Trusted verifiers earn small points.

---

### 3️⃣ Proof Requirements

Certain posts require **evidence**:

Examples:

| Action             | Proof            |
| ------------------ | ---------------- |
| Tree planting      | Photo + location |
| Recycling          | Photo            |
| Public transport   | Ticket / map     |
| Solar installation | Image            |

You can also require:

**Before / After photos**

Example:

Before: dirty park
After: cleaned park

# 3. Preventing Gaming the System

Without safeguards, people will spam fake eco posts.

Solutions:

### Anti-spam

Limit:

```
Max rewarded posts per day: 5
```

### Duplicate detection

AI checks if users reuse the same photos.

### Geo validation

Example:

User says they planted a tree.

GPS metadata confirms location.
